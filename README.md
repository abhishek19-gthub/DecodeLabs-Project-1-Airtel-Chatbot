# Technical Airtel Assistance Chatbot 🤖

A rule-based AI chatbot built in Python as **Project 1** of the **DecodeLabs AI Industrial Training Internship (Batch 2026)**.

The bot works like a telecom customer support assistant. It reads what the user types and replies with the right solution using predefined rules.

## 🔹 Features
- Troubleshooting for **no internet, slow internet, router issues, network issues and SIM problems**
- Quick answers for **balance check, recharge, bill payment and customer care number**
- **Help menu** that lists everything the bot can answer
- **Greeting and exit commands** (`hello`, `hi`, `exit`, `bye`)
- **Follow-up handling** after the user says "ok"
- **Fallback reply** when the bot doesn't understand the input

## 🛠️ Technologies Used
- Python
- Conditional Logic (`if-elif-else`)
- Loops (`while`)
- String Processing (`.lower()`, `.strip()`)

## ▶️ How to Run
1. Install [Python 3](https://www.python.org/downloads/)
2. Download `Project_1.py` from this repository
3. Open a terminal in the file's folder and run:

   python Project_1.py

```text
You: help
AIRTEL BOT: You can ask me about:
- no internet

- how to check balance
- how to recharge
- how to pay bill
- network issue
- sim not working

```
